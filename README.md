# TOSS IA Portfolio Web v1.4.2

## 실행
Windows에서는 압축을 먼저 푼 뒤 `실행.cmd`를 더블클릭하세요.
Python 확인 → `.venv` 생성 → 필요한 패키지 설치 → Streamlit 실행까지 자동입니다.

## v1.3.0 주요 수정
1. 키/몸무게 입력으로 BMI 자동 계산.
2. 보편적 독립 담보라는 전제의 `소득보장` 현재보장 입력 제거. 소득상실 대비는 암·뇌·심장 진단비와 후유장해 충족도로 평가.
3. 질병/상해 정액수술비 + 1~5종 종수술비 별도 입력.
4. 질병/상해 후유장해를 80%미만 / 80%이상으로 분리 입력.
5. 간병인지원(사람)과 간병인사용일당(현금), 치매 월생활자금 분리.
6. 뇌졸중 대신 HIRA 뇌혈관질환(I60-I69), 심근경색 대신 HIRA 허혈성심질환(I20-I25) 통계로 교체.
7. 유사암은 국가 통계의 표준 단일 집계가 없어 전체암 통계를 임의 적용하지 않음. 일반암은 악성암 전체 국가암등록통계를 참고하되 약관 정의와 1:1 동일하지 않음을 표시.
8. 직업명으로 내부 상담용 직업 위험지수 자동 매핑.
9. 토스 공식 브랜드 리소스 원본 로고 URL 사용. 비공식 내부 프로토타입임을 명시.

## 중요한 환산 규칙
- 종수술비: 정액수술비와 3종 금액 중 큰 값을 GAP 분석 대표치로 사용. 실제 지급액 아님.
- 후유장해 80%미만: 가입금액의 30%를 중등도 장해 시나리오로 환산한 값과 80%이상 가입금액 중 큰 값을 대표치로 사용. 실제 보험금 아님.
- 간병인지원(사람): 임의 금액 환산하지 않음.
- 간병인사용일당: 30일을 곱해 월 현금흐름 참고치로 환산.

## 통계 주의
HIRA 자료는 청구 주상병 기준 진료통계이며 최종 확정진단과 다를 수 있습니다. 공개 요약자료에 동일한 연령/성별 비율이 없는 구간은 공식 수치로 표시하지 않고 내부 모델 보간이라고 명시합니다.

## v1.3.1 통계 복원
- v1.3.0의 넓은 HIRA 질환군 통계 적용을 취소했습니다.
- 뇌졸중/심근경색증은 v1.2.2의 2023 성·연령별 공식 발생률로 복원했습니다.
- 전체 암 공식 발생률을 유지합니다.
- 유사암은 별도 표준 공식통계가 없어 전체 암 발생률을 제한적 참고치로 재사용합니다.


## v1.3.2 권장값 수동 수정 기능
- 자동 Needs 권장값을 각 보장별 기본 입력값으로 표시합니다.
- 사용자가 권장값을 직접 수정할 수 있습니다.
- 수정값을 기준으로 GAP, 충족률, 판정, NeedScore, 우선순위, Portfolio Score, 상품한도를 모두 재계산합니다.
- 분석 결과에서 자동권장값과 실제 적용 권장값을 함께 표시하며 수정 여부를 구분합니다.

## v1.3.3 금액 입력 표시 개선
- 원화 금액 입력란에 천 단위 쉼표(,) 표시를 적용했습니다.
- `50000000` 또는 `50,000,000`처럼 입력할 수 있으며 내부 계산에는 정수 원화로 전달됩니다.
- 입력란 아래에 해석된 금액을 `50,000,000원` 형식으로 즉시 표시합니다.
- 연소득, 생활비, 보험료, 자산/부채, 현재보장, 종수술, 후유장해, 간병, 권장값 수정, 상품한도에 모두 적용했습니다.

## v1.3.4 실시간 원화 입력
- 금액을 타이핑하는 즉시 입력창 안에서 `₩ 59,000,000 원` 형태로 천 단위 쉼표가 적용됩니다.
- 입력창 아래에 `오천구백만 원`처럼 한글 금액이 실시간 표시됩니다.
- 별도 외부 패키지가 아니라 프로젝트에 포함된 로컬 Streamlit 컴포넌트를 사용합니다.
- 모든 원화 입력란(소득, 자산, 보험료, 현재보장, 종수술, 후유장해, 간병, 권장값, 상품한도)에 적용됩니다.

## v1.4.2 Web 전용
- Python 설치 없이 브라우저에서 사용하는 Streamlit Community Cloud 배포 구조입니다.
- 고객명은 상담번호/가명으로 변경했습니다.
- 직업 자유입력을 넓은 직업군 선택으로 변경하여 재식별 가능성을 낮췄습니다.
- 병원명/상세 질병명/진단일/수술일 등 직접적인 민감 상세정보를 받지 않습니다.
- 고객 입력값이나 분석 결과를 DB/CSV/로그 파일에 영구 저장하는 기능은 포함하지 않았습니다.
- 웹 처리 특성상 입력값은 Streamlit 서버로 전송되어 계산된다는 사실을 앱에 명시했습니다.
- 실시간 원화 입력, 한글 금액 읽기, GAP 수정, 통계, 점수 기능은 유지합니다.


## v1.4.2 로컬 실행 지원
- `실행.cmd`: 일반 사용자용 자동 실행
- `run.cmd`: 오류 진단/복구용 상세 실행
- Streamlit 서버는 로컬 `127.0.0.1:8501`에 바인딩
